# 채점 엔진 MVP 규칙

- 원본 역채점 표시를 그대로 사용한다. 문구 의미에 따른 수정은 하지 않는다.
- 응답은 문항 ID를 키로 받는다. 없는 키 또는 `undefined`는 결측이다. `null`, 문자열, 소수, 1~5 밖의 값과 알 수 없는 ID는 오류로 처리한다.
- 차원별 3~4개 유효 응답은 보정점수 평균을 계산한다. 0~2개 응답은 `pending`이며 평균과 환산점수는 `null`이다. 계산값을 반올림하지 않는다.
- 순위는 경쟁 순위(예: 1, 1, 3)를 사용한다. 공동순위 내 배열 순서는 원본 차원 순서이며 우열을 의미하지 않는다. 상위 3개는 3위 이내 전체를 반환하므로 공동 3위가 있으면 3개를 초과할 수 있다.
- CORE 차이는 점수순 첫 두 차원의 차이다. 공동 1위는 차이 0, 근접 `true`다. 5점 미만만 근접이며 정확히 5점은 아니다.
- 산출 보류 차원은 순위에서 제외하고 별도 코드 목록에 남긴다. 일부 차원이 보류된 순위는 `partial`로 표시한다. CORE가 하나라도 보류되면 전체 상위 비교를 확정하지 않으며 차이와 근접 여부는 `null`이다.
- 요청한 PATTERN 상위 3위는 점수 제한 없이 `pattern.top`에 반환한다. 기존 명세의 60점 이상 대표 패턴은 별도 `pattern.representative`에 반환한다. DIRECTION도 공동순위를 보존한 상위 3위를 반환한다.
- ANX와 AVO는 각각의 점수·결측 상태로 반환한다. 단일 관계 유형이나 총점을 만들지 않는다.
- 응답 품질은 역채점 전 원응답을 사용한다. 분모는 미응답을 포함한 전체 108문항이다. 동일 응답의 최다 개수와 1 또는 5의 합계가 각각 전체의 90% 이상이면 경고한다. 108문항에서는 98개부터 경고한다.
- 경고는 계산 결과를 변경하거나 무효화하지 않는다. 결측으로 인한 산출 보류와 응답 품질 경고는 별개다.
- 현재 엔진은 점수와 순위만 분석한다. 교차해석·반증 문장 생성, AI 호출, 영역 평균과 강도 라벨은 이번 구현 범위에 포함하지 않는다.
- `npm.cmd test`는 TypeScript를 임시 디렉터리에 컴파일한 뒤 Node 내장 테스트 러너를 실행한다. 종료 시 임시 산출물을 정리한다.
