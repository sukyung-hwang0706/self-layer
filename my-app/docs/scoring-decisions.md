# 채점 규칙 (V1.0 · `v1.0-app.1`)

기준: `project_sources/SELF-LAYERS V1.0 검사 설계서` 10장. 모든 가중치·임계값은 설계서가 밝힌 대로 **파일럿 전 가설값**이다. 채점은 `src/lib/scoring.ts`의 순수 함수 `scoreAssessment`가 수행하며 UI·네트워크·시각·무작위값에 의존하지 않는다.

## 설계서를 그대로 따른 규칙

| 항목 | 규칙 |
|---|---|
| 기초 채점 | 역문항 `6 − 응답`, 0–100 환산 `(평균 − 1) / 4 × 100` |
| Core | 1순위 +2, 2순위 +1. `TypeScore = raw / 12 × 100`. `CoreSeparation = min(100, (Top1Raw − Top2Raw) / 4 × 100)` |
| CoreConfidence | `0.50·Top1TypeScore + 0.20·Separation + 0.30·M(Top1) − Penalty` (0–100으로 제한) |
| Primary 동점 | TypeScore → M(Tn) → 1순위 선택 횟수. 셋 다 같으면 `status: "undetermined"`(혼합/판정 유보) |
| 플래그 | M(Top1) < 40 → 동기 진술 약함. M(Top2) ≥ 75 이고 TypeScore 차이 ≤ 8 → 강한 보조 Core |
| 응답 일관성 | 스키마 정·역 쌍이 역채점 후 4점 이상 차이 나는 스키마가 4개 이상 → 플래그, Confidence −5 |
| Value | 같은 문항 안 같은 Value 득점은 최대 2점 |
| STATE | `0.35·SC + 0.35·FLX + 0.30·mean(N-AUT, N-COM, N-REL)`. 밴드 ≥70 여유 / 45–69 평소 / <45 보호 |
| Stress | 취약 트리거 = ST ≥ 65 중 상위 최대 2개. 지배 대처 = 최댓값(동점 모두). 반응성 ≥70 높음 / 40–69 보통 / <40 낮음. Core 일치 = 취약 트리거의 연결 Core에 Primary 포함 |
| Expansion | `0.55·STATE + 0.25·(100 − SR) + 0.20·(100 − max ST)` |
| Protection | `0.40·SC[stress(Core)] + 0.35·(100 − STATE) + 0.25·SR` (대처 매핑은 7장 표) |
| 모드 밴드 | ≥70 / 45–69 / <45 |
| Growth 준비도 | `0.40·STATE + 0.35·Expansion + 0.25·N-REL`. ≥65 실험 3개, 45–64 2개, <45 성찰 질문 |
| 메시지 | `0.60·TypeScore + 0.40·Resonance`. 2위와 8점 이내면 두 문장 표시. 1위 ≠ Primary면 교차 통찰 |
| 표현 채널 | Part 6 순위 1위 100 · 2위 50 · 3위 0, 1순위를 표현 채널로 사용 |

## 설계서에 정의가 없어 앱에서 정한 임시 규칙

설계서가 "V0.2 규칙 유지"라고만 적고 식을 제공하지 않은 부분이다. 원본 규칙이 아니며, V0.2 문서가 확보되면 교체한다.

1. **Value 점수**: `ValueSelection = 제한 득점 / 도달 가능한 최대 득점 × 100`. 도달 가능한 최대는 문항당 2점 × 그 Value가 등장하는 문항 수다. 설계서 4장은 EXP 최대 12점·GROW 14점이라 적었지만 문항당 2점 제한을 적용하면 실제 최대는 EXP 8점·GROW 12점이므로 실제 최대를 분모로 쓴다. `ContextDiversity = 득점한 맥락 태그 수 / 그 Value가 등장하는 맥락 태그 수 × 100`. 최종 `0.6·Selection + 0.4·Diversity`. top3는 점수 → 정의 순서로 자른다.
2. **Influence**: Primary의 인접 두 Core 중 raw가 높은 쪽. raw가 같으면 "뚜렷한 Influence 없음"(설계서 11장 "Raw 차이 ≥ 1").
3. **판정 유보 시 기준 Core**: 동점 후보 중 정의 순서가 앞선 Core를 Protection·메시지 일치 등 계산 기준으로 쓰고, 화면에는 동점 후보를 모두 밝히며 단정 문장을 쓰지 않는다.
4. **강화(Reinforcement)**: Primary·Secondary 각각에 대해 메시지 Resonance와 같은 연결 변수를 쓴다(T1–US, T2–SS, T3–AS, T4–DEF, T5–AVO, T6–mean(ANX, ABN), T7–ST4, T8–MIS, T9–ST5). Core ≥ 50, 연결 변수 ≥ 60, 강도 = 평균 ≥ 55일 때 표시한다. 문장 강도는 V0.2 밴드(55–69 가능성 / 70–84 경향 / 85+ 반복)를 따른다.
5. **반증(Counterevidence)**: Primary의 전형 신호(T1 US, T2 SS, T3 AS, T4 DEF·ED, T5 AVO, T6 ANX·ABN·MIS, T7 ST4, T8 MIS, T9 SS·ST5)의 평균이 45 미만이면 "전형적인 설명이 전부는 아닙니다"를 표시한다. 점수나 순위는 바꾸지 않는다.
6. **Core 문장 강도**: 판정 유보·동기 진술 약함이면 "가까워 보여요", CoreConfidence ≥ 70 "~예요", 55–69 "~에 가까워요", 그 밖은 가능성 표현.
7. **표시 구간**: 차트 띠 <40 낮음 · 40–59 중간 · 60–74 다소 높음 · ≥75 높음. 판정에는 쓰지 않는다.
8. **관계 지도 사분면**: ANX·AVO 각각 50 기준. 두 축은 독립 점수로 함께 표시하며 단일 유형 점수를 만들지 않는다.
9. **완전 응답만 채점**: 설계서에 결측 규칙이 없으므로 76문항 모두 유효할 때만 결과를 만든다. 동일 선택지를 1·2순위로 고른 응답, 1–5 밖의 값, 중복 순위는 미응답으로 본다.
10. **경계값**: 계산 중간값은 반올림하지 않고 원값으로 밴드를 판정한다(예: 69.99는 평소 밴드). 화면 표시만 정수로 반올림한다.

## 사용하지 않는 것

- 사람 검토·메일 발송, 무료 간단검사(Part 1만) 흐름은 설계서 12장의 운영 범위이며 이번 MVP에 포함하지 않았다. AI 문장화는 [ai-narrative.md](ai-narrative.md)를 따른다.
- 문항·역채점 표시는 설계서 원문 그대로이며 임의로 수정하지 않았다.
