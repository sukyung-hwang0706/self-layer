# 검사·결과 화면 안내

## 검사 화면 (`/`, `/survey`)

- **인트로**: 6 Part 구성과 문항 수, 예상 시간(약 18분), 리포트에 표시할 이름(선택, 20자). 응답이 있으면 "이어서 하기"가 첫 미응답 문항으로 이동한다.
- **진행 표시**: 상단에 Part별 6칸 진행 막대(Part 색상 = Layer 색상), 전체 응답 수, 남은 예상 시간.
- **Part 안내**: 각 Part의 첫 문항 위에 질문과 안내문을 보여준다. Part 4는 "다음 상황에서 나는 평소보다 크게 흔들린다." / "힘들 때 나는…", Part 5는 "지난 한 달 동안,"을 문항 위에 고정한다.
- **응답 방식**
  - Part 1 (상황 선택): 세 선택지 중 1순위 → 2순위 순서로 누른다. 선택한 것을 다시 누르면 취소되고, 남은 선택이 1순위가 된다. 두 개를 고른 상태에서 다른 것을 누르면 2순위가 바뀐다.
  - Part 2–5 (5점 평정): 라디오 버튼. 터치·클릭으로 고르면 0.26초 뒤 다음 문항으로 넘어가고, 키보드(방향키·스페이스)로 고르면 자동으로 넘어가지 않는다.
  - Part 6 (순위): 가까운 순서대로 누른다. 두 개를 고르면 남은 하나가 3순위가 된다.
- **응답 확인**: Part별 번호 버튼(응답함/미응답을 색과 점선·라벨로 구분). 미응답이 있으면 제출하지 않고 남은 개수를 알린다.
- **저장**: `localStorage`의 `self-layers:v1.0:session`. 저장값은 복구 시 문항 은행 기준으로 검증한다. 해시(`#start`, `#q1`–`#q76`, `#review`)로 브라우저 뒤로가기를 지원한다.

## 결과 화면 (`/result`)

SAMPLE 리포트 구조를 따른 16개 섹션: 표지 → 소개 → 한 사람으로 읽기 → Self Map → Core → Influence·보조 Core → 지금의 나(STATE) → 두 가지 모드 → 오래 확인하고 싶었던 말 → 관계 → 패턴 → Stress Signature → 가치 → 교차 해석 → 성장 → 편지·Self Card.

- 상단 고정 목차(가로 스크롤 칩)와 하단 "인쇄 · PDF로 저장 / 응답 확인·수정 / 새로 검사하기".
- 차트는 SVG(레이더, 게이지, 관계 지도, 겹침)와 HTML 막대로 그리며 모든 수치를 텍스트로 함께 표시한다.
- 문장은 `src/data/content.ts`의 고정 문구와 채점 결과로 조합한다. 상단 "AI로 문장 다듬기"를 누르면 검증을 통과한 AI 문단(점선 표시)이 6개 문단을 대신하며, "기본 문장으로 보기"로 되돌릴 수 있다([AI 문장화](ai-narrative.md)).
- 사용자 화면 금지어(유형번호, Wing/윙/날개, 통합/분열, 내부 코드)는 단위 테스트와 E2E 테스트가 확인한다.
