# AI 문장화 (`narrative-v1`)

설계서 10장 흐름 "Confidence → 템플릿 → **AI 문장화** → 사람 검토" 중 AI 문장화 단계를 구현했다. 사람 검토 단계는 아직 없다.

## 원칙

- AI는 **판정하지 않고 문장만 쓴다.** 점수·순위·Core·밴드·교차 규칙은 모두 `scoreAssessment`가 확정하고, AI 출력은 계산 결과를 덮어쓰지 않는다.
- 결과 화면은 언제나 고정 문구(템플릿)로 완성되어 있고, 검증을 통과한 AI 문단만 해당 템플릿 문단을 대신한다. 사용자는 "기본 문장으로 보기"로 되돌릴 수 있다.
- 사용자가 결과 화면에서 **직접 버튼을 눌러야** 호출한다.

## 흐름

1. 브라우저 → `POST /api/narrative` `{ answers }`. 이름은 보내지 않는다.
2. 서버가 `missingItems`로 응답을 검증하고 **서버에서 다시 채점**한다(클라이언트가 보낸 점수는 받지 않는다).
3. `buildNarrativeInput`이 확정 결과를 사실 목록으로 바꾼다. 내부 코드(T1, SS 등)·원응답·점수 숫자·이름을 넣지 않는다. 호칭은 `{nm}` 자리표시자로 쓰게 하고 화면에서 치환한다.
4. Claude(`claude-opus-5`, `fallbacks: "default"`)가 `output_config.format` JSON 스키마로 6개 필드(summary, core, modes, message, cross, letter)를 쓴다.
5. `validateNarrative`가 필드별로 검사하고 통과한 문단만 돌려준다. 결과는 같은 응답일 때 다시 쓰도록 브라우저에 저장한다.

## 검증 규칙 (`src/lib/narrative.ts`)

| 거부 사유 | 기준 |
|---|---|
| 금지 용어 | 유형번호, Wing/윙/날개, 통합/분열, 내부 코드 |
| 숫자 | 모든 숫자(점수를 바꾸거나 새로 만드는 것을 막음) |
| 진단·치료 표현 | 진단, 질환, 장애, 증상, 치료, 처방, 병원 등 |
| 성장환경 추정 | 어린 시절, 부모, 가족사 등 |
| 비교·순위 | 상위, 백분위, 남들보다 등 |
| 근거 없는 Core | 이번 결과(주·보조·Influence·동점·메시지)에 없는 Core 이름 |
| 다른 호칭 | `{nm}` 외의 자리표시자, "당신" 등 |
| 보호 상태 과제 | 실험 0개 밴드에서 실험·과제 제안 |
| 형식 | 빈 값, 40자 미만·900자 초과, 마크다운 |

## 설정

- 서버 환경 변수 `ANTHROPIC_API_KEY`(또는 SDK가 인식하는 다른 자격 증명)가 필요하다. 로컬에서는 `my-app/.env.local`에 넣는다(커밋하지 않는다).
- 자격 증명이 없으면 API가 `503 ai_unavailable`을 돌려주고 화면은 기본 문장을 유지한다.
- 오류 코드: `400 invalid_answers`, `429 rate_limited`, `502 refused | truncated | invalid_output | ai_error`, `503 ai_unavailable`.

## 테스트

- `src/lib/narrative.test.ts`: 입력에 내부 코드·숫자가 없는지, 검증 규칙별 거부, 보호 상태 규칙.
- E2E: API를 가짜 응답으로 대체해 호출 조건(버튼), 이름 미전송, 적용·전환·재사용, 503 안내를 확인한다. 실제 Claude 호출은 자동 테스트에 포함하지 않는다.
