# 작업보고서

작업을 마친 후 사용자가 커밋과 함께 작업보고서 생성을 요청하면 이 폴더에 보고서를 작성합니다.

## 파일 규칙

- 경로: `docs/work/YYYY-MM-DD.md`
- 날짜: Asia/Seoul 기준 작성일
- 예시: `docs/work/2026-09-22.md`
- 같은 날 추가 작업은 기존 보고서에 작업별 항목으로 덧붙입니다.
- 보고서를 먼저 작성한 뒤 관련 변경 사항과 함께 커밋합니다.

## 보고서 형식

```markdown
# YYYY-MM-DD 작업보고서

## 작업 1: 작업명

### 작업 목적

이번 작업의 목적을 기록합니다.

### 주요 변경 사항

- 변경 내용과 관련 파일을 기록합니다.

### 검증 결과

- 실제 수행한 검사나 테스트와 결과를 기록합니다.
- 검증하지 않았다면 그 사실과 이유를 기록합니다.

### 미완료 사항 및 다음 작업

- 남은 사항을 기록합니다. 없으면 없음으로 표시합니다.
```
