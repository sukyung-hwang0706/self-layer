## 작업 1: V1.2 개선계획 수립과 검증 기반 마련

### 작업 목적

### 주요 변경 사항

- `docs/plan-v1.2.md`: 결정 요약, 원칙(복수 Core 해석, 반증은 해석 문장 조정에만 사용, 세 중심은 보조 해석), 단계별 실행 순서(0→2→1→3~6), 검증할 해석 주장 C1~C6, EXP 정의, 가치 채점 보정 결정.
- 기준선 보관: `validation/archive/round3-v1.1/`(V1.1-app 몬테카를로·구조·설계서 차분·페르소나 30명 결과).
- 별도 검증 페르소나 15명: `validation/holdout-brief.md`, `validation/holdout/`(h01–h15 bio·정답지·배치표). 규칙 조정 중에는 열지 않는다.
- 강한 보조 Core 조건을 환산 점수 차이(≤ 8)에서 원점수 차이(≤ 1)로 옮겼다(`src/lib/scoring.ts`, 결과 변화 없음).

### 검증 결과

- 원점수 전환: 설계서 차분 2,350세트 불일치 필드 1개(기존 동점 목록 표기 차이), 몬테카를로는 버전 문자열 외 동일, 페르소나 30명 결과가 보관본과 동일.

### 미완료 사항 및 다음 작업

## 작업 2: 가치 채점 보정(B안) 비교와 적용

### 작업 목적

무작위 응답에서도 특정 가치가 1위로 자주 나오는 쏠림을 줄인다. 문항 배치만으로는 문장의 자연스러움과 충돌해 해소하기 어려워, 채점 보정 후보를 비교한 뒤 B안을 적용했다.

### 주요 변경 사항

- 원인 분석: Selection 점수만으로는 가치가 고르게 나오지만, 맥락 다양성 공식과 등장 횟수 차이(변동 폭)가 쏠림을 만든다(`validation/scripts/value-components.ts`, `value-ties.ts`).
- 후보 비교(`validation/scripts/value-calibration.ts`, `docs/drafts/value-scoring-candidates.md`): A(Selection 표준화), B(결합 점수 표준화), C(무작위 분포 내 위치). 보정 세트와 평가 세트를 분리했다. B안을 잠정 채택했다.
- 허용폭·보정 시드 비교(`validation/scripts/value-tolerance.ts`): 0.025·0.05·0.10, 보정 시드 3개.
- 구현(`src/lib/value-calibration.ts`)
  - 배치 지문(문항 버전·맥락·가치 태그·배점 상한·결합 비중·보정 방식). 맞지 않으면 오류를 낸다.
  - 공동 1위(최고점과 z 0.05 이내), 상위 3 경계 공동, 전체 공동 순위(연쇄 포함 없음).
- 보정값 산출 스크립트 `validation/scripts/make-value-calibration.ts` → `src/data/value-calibration.ts`(자동 생성, 무작위 20,000세트, 지문 5463afe5).
- 채점(`src/lib/scoring.ts`, `SCORING_VERSION v1.2-app.2`)
  - `scoreUncalibrated`와 `applyValueCalibration`으로 나눴다. 결합 점수는 그대로이고 가치 순위만 보정 점수로 정한다.
  - 가치별 등장 기회·선택 수를 결과에 추가했다(`src/types/assessment.ts`).
- 리포트(`src/components/report/report.tsx`, `src/lib/report.ts`, `src/app/globals.css`)
  - 가치 막대그래프를 순위·공동 순위 목록과 선택 근거("N번의 기회 중 M번 선택 · 제시된 상황 X종류 중 Y종류에서 선택")로 바꿨다. 0~100 점수 표시는 뺐다.
  - Self Map의 가치 축은 공동 1위의 실제 선택 비율이다.
- AI 문장화(`src/lib/narrative.ts`, `NARRATIVE_VERSION narrative-v2`): 가치 사실에 공동 순위를 숫자 없이 말로("[공동 가장 앞섬]") 넣었다.
- 검증 스크립트의 보정 전 기준선과 페르소나 집계를 공동 1위 기준으로 고쳤다(`summary.ts`, `analyze.ts`, `compare-versions.ts`).
- 문서: `docs/scoring-decisions.md` 임시 규칙 11(B안)을 추가했다.

### 검증 결과

- 무작위 응답 10,000세트(V1.2-app)
  - 보정 전: 가치 1위 8.8~15.4%, 상위 3 포함률 29.5~42.8%
  - 보정 후: 가치 1위 11.5~13.4%, 상위 3 포함률 38.5~39.8%(기준 12.5% ±2%p, 37.5% ±5%p)
- 보정 시드를 바꾸면 가치별 평균이 표준편차의 0.016 이하로 달라지고, 공동 1위 집합이 달라지는 응답은 1.4%였다(u3 배치 기준).
- 허용폭 0.05는 잠정 근접 기준이며 검증된 동점 기준이 아니다.

### 미완료 사항 및 다음 작업

- 보정은 무작위 응답 기준의 구조적 쏠림만 줄인다. 실제 사람 분포에서의 적절성은 파일럿 데이터로 확인해야 한다.
- 문항 배치가 바뀌면 `make-value-calibration`을 다시 실행해야 한다(테스트가 불일치를 잡는다).

- 앱 검사(최종, `my-app/`에서 실행)
  - `npm.cmd run lint`: 통과
  - `npm.cmd run typecheck`: 통과

  - `npm.cmd run test:e2e`(모바일·데스크톱): 20개 통과. 가로 스크롤 없음과 금지어 미노출 포함.
