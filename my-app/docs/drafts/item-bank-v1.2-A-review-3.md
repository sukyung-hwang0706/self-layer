# 문항 은행 V1.2-app A안 · 18문항 초안 검토표 (3차, u3 배치)

작성 2026-10-04. `items.ts` 반영 전 검토용이다. 2차 초안([item-bank-v1.2-A-review.md](item-bank-v1.2-A-review.md))의 판독 결과와 검토 의견을 반영했다. 보기 위치(A~D)는 아직 확정하지 않았으며 아래 순서는 작성용이다.

## 1. 이번 초안의 조건

- 배치: u3(가치 CONTR 8·REL 10·나머지 9회, Core 각 8회, 18문항 모두 중심 2·1·1). 가치 쏠림은 B안 채점 보정으로 다룬다([value-scoring-candidates.md](value-scoring-candidates.md)).
- DEPTH·CONTR는 이번 후보에서 잠정 제외(CARE로 읽힘). DEPTH가 기여를 중시하지 않는다는 뜻이 아니다.
- E07에 ORDER의 "잘못된 것을 그냥 넘기지 못함"을 복원(보호 대상은 문장이 아니라 측정 내용).
- 의미 문제(의도한 Core·가치가 드러나지 않음)와 어조 문제(유난히 모범적·부정적)를 따로 고쳤다.
- 2차 판독에서 다르게 읽힌 기존 보기(TRUST의 E09·E12, E02 INSIGHT 등)도 이번에 고쳤다. B안 단계로 미루지 않는다.

표기: ★ 새 보기 · ◆ 기존 문장을 고침 · 유지 · ⚠ 판독에서 다시 볼 점

### 의미 문제

**Core가 다르게 읽힘**
