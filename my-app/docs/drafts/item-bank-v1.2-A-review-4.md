# 문항 은행 V1.2-app A안 · 18문항 초안 검토표 (4차, 4.1 수정 반영)

작성 2026-10-04. `items.ts` 반영 전 검토용이다. **이 문서의 4.1 문장은 [4.2 검증용 후보](item-bank-v1.2-A-candidate.md)로 대체되었다.** 5장의 판독 수치는 4차 판독본 문장에 대한 것이며 4.1·4.2 문장을 검증한 수치가 아니다. 3차([item-bank-v1.2-A-review-3.md](item-bank-v1.2-A-review-3.md))의 두 독립 판독과 검토 의견을 반영했다.

## 1. 이번 수정의 원칙

- 가치는 고친 문장에 실제로 드러나는 것을 배정한다. 두 판독의 일치는 재검토 근거이며 자동 정답이 아니다.
- E15는 CARE·CONTR / STAND·AUT / DEPTH·REL / TRUST·SEC 재배정을 후보로 허용(모호함·어조를 고친 최종 문장으로 다시 확인).
- E07은 ORDER의 "잘못된 것을 그냥 넘기지 못함"을 보존하고, 가치는 문장에 맞춰 AUTH로 둔다. GROW 횟수를 위해 E07 문장을 바꾸지 않는다.
- 가치별 8~10회는 관리 목표다(절대 조건 아님). 벗어나면 내용 범위와 보정 결과를 함께 본다.
- 의미 문제와 어조 문제를 따로 고친다.

표기: ★ 새 보기(이번 배치에서 새로 씀) · ◆ 이번 회차에 고침 · 유지

## 4. 가치 등장과 내용 범위, 구조

| 가치 | 횟수 | 붙은 Core(보기 수) | 확인할 점 |
|---|---:|---|---|
| ACH | 9 | DRIVE 8, STAND 1 | |
| AUT | 10 | STAND 6, INSIGHT 4 | |
| REL | 9 | FLOW 5, DEPTH 2, CARE 1, TRUST 1 | FLOW에 몰림. E02 TRUST는 장면 효과로 REL |
| SEC | 10 | TRUST 7, FLOW 2, ORDER 1 | TRUST에 몰림 |
| GROW | 8 | INSIGHT 4, ORDER 3, DEPTH 1 | 공부·업무 장면만이 아니라 회복·변화·규칙 장면에도 있음 |
| AUTH | 9 | DEPTH 5, ORDER 4 | |
| CONTR | 8 | CARE 7, STAND 1 | CARE에 몰림 |
| EXP | 9 | SPARK 8, FLOW 1 | SPARK에 몰림 |

- Core는 각 8회, 18문항 모두 중심 2·1·1.
- Core 짝 균형: 14쌍이 목표 범위를 1회씩 벗어난다(같은 중심 쌍 2회 목표 → ORDER–STAND 3, ORDER–FLOW 1, INSIGHT–TRUST 1, INSIGHT–SPARK 3 / 다른 중심 쌍 3~4회 목표 → ORDER–DRIVE·CARE–STAND·DRIVE–INSIGHT·DEPTH–FLOW 5, ORDER–CARE·ORDER–DEPTH·CARE–INSIGHT·DRIVE–TRUST·DRIVE–STAND·SPARK–STAND 2). 실제 횟수는 1~5회다(4.2 후보 4장). q3(4쌍 이탈)보다 넓어졌으며, 반대 근거 판단에서 함께 제시된 기회를 셀 때 이 차이를 반영한다.
- 가치 배정이 특정 Core에 몰리는 것(EXP–SPARK, CONTR–CARE, SEC–TRUST)은 Core와 가치가 같은 응답에서 함께 올라가는 구조를 강화한다. Core와 가치를 서로의 검증 근거로 쓰지 않는다는 원칙을 유지한다.
