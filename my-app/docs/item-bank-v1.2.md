# 문항 은행 V1.2-app (검증용)

- 버전: `ITEM_BANK_VERSION = "1.2-app"` · `SCORING_VERSION = "v1.2-app.2"`(가치 순위 보정 적용; 문항 반영 시점은 v1.2-app.1) · 세션 저장 키 `self-layers:v1.2:session`
- 상태: **검증용**. 조정용 페르소나 재응답과 실제 사용자 인지면담으로 확인하기 전까지 확정 문항이 아니다.
- 바뀐 범위: Part 1(E01~E18)의 보기 구성·문장·가치 태그와 일부 질문. Part 2~6, 문항 ID, 노출 순서, 채점 규칙은 그대로다.
- 근거 문서: [plan-v1.2.md](plan-v1.2.md) 1단계, 검증용 후보와 판단 기록 [drafts/item-bank-v1.2-A-candidate.md](drafts/item-bank-v1.2-A-candidate.md)(4.4), 작성 경과 [2차](drafts/item-bank-v1.2-A-review.md)·[3차](drafts/item-bank-v1.2-A-review-3.md)·[4차](drafts/item-bank-v1.2-A-review-4.md), 가치 보정 [drafts/value-scoring-candidates.md](drafts/value-scoring-candidates.md).

## 왜 바꿨나

V1.1-app은 무작위 응답에서도 가치 1순위가 AUTH로 19%까지 쏠렸다(기대 12.5%). 원인은 가치마다 등장하는 맥락 구성이 달라 맥락 다양성 점수가 일부 가치에 유리했기 때문이다. 또 Part 1의 일부 보기가 다른 Core로 읽히거나 모범답안처럼 보였다.

## 구조

| 항목 | V1.1-app | V1.2-app |
|---|---|---|
| Core 등장 | 각 8회, 위치 A~D 각 2회 | 같음 |
| 세 중심(본능 T8·T9·T1 / 감정 T2·T3·T4 / 사고 T5·T6·T7) | 문항마다 다름(중심별 도달 가능 최대 38·35·39점) | 모든 문항 2·1·1(중심별 최대 42점) |
| 가치 등장 | AUTH 10, EXP 8, 나머지 9 | AUT·SEC 10, GROW·CONTR 8, 나머지 9(관리 범위 8~10회) |
| 문항 안 가치 중복 | 없음 | 없음 |
| Core 짝이 같은 문항에 함께 나오는 횟수 | — | 1~5회(목표 이탈 14쌍, 후보 문서 4장) |

- 가치 등장 횟수 차이와 맥락 배치에 따른 쏠림은 문항 배치만으로 해소하기 어려워, 가치 순위는 B안(결합 점수를 가치별 무작위 평균·표준편차로 표준화) 보정으로 다룬다. `v1.2-app.2`부터 리포트에 적용했다(보정값 `src/data/value-calibration.ts`, 지문 5463afe5). 무작위 응답 기준 가치 1위 11.5~13.4%, 상위 3 포함률 38.5~39.8%(보정 전 V1.2-app은 8.8~15.4%, 29.5~42.8%).
- DEPTH·CONTR 조합은 CARE로 읽혀 이번 버전에서 잠정 제외했다(DEPTH가 기여를 중시하지 않는다는 뜻이 아님).
- EXP는 "새로움을 통해 얻는 즐거움과 자극"으로 정의한다. 익숙하고 편안한 휴식만으로는 EXP를 부여하지 않는다.

## 확인 방법과 한계

- 태그를 가린 AI 독해 점검(2차 1회, 3차 2회, 4차 2회, 4.2~4.4 변경 문항 집중 점검). 4차 두 판독 모두 Core 68/72, Value 69/72가 의도대로 읽혔다. 이후 고친 문장(4.1~4.4)은 변경 문항만 점검했다. 마지막 E15 TRUST 문장은 판독하지 않았다.
- AI 판독은 실제 응답자가 왜 그 보기를 고르는지 대신하지 않는다. 남은 표현 문제는 후보 문서 6장의 인지면담 질문으로 확인한다.
- 같은 선택에서 Core와 가치가 함께 올라가는 구조가 강하다(ACH는 DRIVE에 8/9, EXP는 SPARK에 8/9, CONTR는 CARE에 7/8, SEC는 TRUST에 7/10). 가치 결과를 Core와 독립된 근거로 설명하지 않는다.
- 테스트(`src/lib/items.test.ts`): 문항 수, Core 등장·위치 균형, 가치 등장(8~10회), 문항 안 가치 중복 없음, 중심 2·1·1.
