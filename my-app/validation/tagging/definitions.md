# 태그 블라인드 독해용 정의 (blind tagger 전용)

보기 문장만 읽고 그 문장이 드러내는 **동기(Core)**와 **가치(Value)**를 판단할 때 쓰는 정의다. 문항 데이터의 실제 태그는 보지 않는다.

## Core — 그 선택을 하게 만드는 마음(왜)

| 이름 | 핵심 동기 | 흔히 드러나는 모습 |
|---|---|---|
| ORDER | 옳은 기준을 지키고 더 나은 쪽으로 바로잡고 싶음 | 맞고 틀린 것, 고칠 점이 먼저 보임 |
| CARE | 누군가에게 필요한 사람이 되고 싶음 | 사람의 필요를 먼저 알아보고 곁을 지킴 |
| DRIVE | 해내야 가치 있다고 느낌 | 목표와 결과, 해낸 것으로 자신을 확인 |
| DEPTH | 나다운 의미와 감정의 깊이를 찾음 | 감정의 결, 진짜로 통하는 관계, 나만의 색깔 |
| INSIGHT | 충분히 이해한 뒤 움직이고, 스스로 생각할 공간이 필요 | 한발 물러서 관찰, 구조와 원리 파악, 혼자의 시간 |
| TRUST | 믿을 수 있는 기반을 찾고 미리 대비 | 믿을 만한 사람·기준 확인, 위험 대비 |
| SPARK | 새로운 가능성과 즐거움을 누리고 싶음, 답답함을 못 견딤 | 새 선택지, 즉흥, 막힌 곳에서 다른 길 |
| STAND | 휘둘리지 않고 스스로 서며 앞에 나서서 지킴 | 정면으로 다룸, 스스로 판단·결정, 내 사람을 지킴 |
| FLOW | 평화와 조화, 갈등과 자기주장을 피함 | 분위기를 부드럽게, 서두르지 않음, 맞춰 줌 |

## Value — 그 선택에서 중요하게 여기는 것(무엇)

| 코드 | 이름 | 질문 |
|---|---|---|
| ACH | 성취 | 원하는 것을 실제로 이루고 있는가 |
| AUT | 자율 | 내 방식과 속도로 선택하고 있는가 |
| REL | 관계 | 중요한 사람과 마음이 이어져 있는가 |
| SEC | 안정 | 예측할 수 있고 흔들리지 않는 기반이 있는가 |
| GROW | 성장 | 어제보다 더 깊이 알고 나아지고 있는가 |
| AUTH | 진정성 | 내 기준과 색깔에 맞게 살고 있는가 |
| CONTR | 기여 | 내가 누군가에게 실제로 도움이 되는가 |
| EXP | 경험·즐거움 | 새롭고 즐거운 경험이 있는가 — 새로움을 통해 얻는 즐거움과 자극. 익숙한 것을 편안하게 즐기는 휴식, 간섭 없는 선택(AUT), 실력을 높이려는 공부(GROW)만 드러난 문장은 EXP가 아니다 |

## 판단 방법

1. 문장에 쓰인 단어("배운다", "돕는다", "재미있다")가 아니라, 그 행동을 고르는 **이유**로 판단한다.
2. Core와 Value는 따로 판단한다. Core가 분명해도 Value 근거가 약할 수 있다.
3. 확신 정도를 high / mid / low로 적고, 두 번째로 가능한 Core가 있으면 함께 적는다.
4. 같은 문항의 네 보기를 비교해, 유난히 모범적이거나 부정적으로 보이는 보기를 표시한다.
