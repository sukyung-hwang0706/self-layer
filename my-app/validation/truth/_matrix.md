## 점검 결과

### 1. 같은 Core 3명이 서로 다른 사람으로 읽히는가 — 통과
9개 Core 모두 나이대·직업·거주지·가족 구성·말투가 겹치지 않는다(예: T1 = 40대 감사 차장 / 20대 원무과 직원 / 30대 UX 리서처). 장면의 결도 Supporting 수준에 따라 갈린다(자기기준 높음 → 퇴근 후 재작업, 낮음 → 실수를 금방 잊음, 중간 → 체크리스트 한 줄 추가). 제목 한 줄 소개도 "A하지만 B하는" 같은 틀로 반복되지 않도록 문형을 바꿨다. 다만 p17(T6)과 p18(T6)은 둘 다 "미리 확인·대비" 장면이 많아 직업 맥락(안전관리/약국)으로만 갈리는 부분이 있다.

### 2. bio 금지어 검사 — 0건(수정 1건 반영 후)
Glob으로 p01–p30 bio 30개를 찾고 Read로 전부 다시 읽었다. 확인 대상: 유형, 에니어그램, 스키마, 애착, Core, T1~T9, ORDER·CARE·DRIVE·DEPTH·INSIGHT·TRUST·SPARK·STAND·FLOW, 회피형·불안형, 점수, 진단명, 가치 라벨 나열.
- 발견 1건: p24 자기 인식의 "리더 타입이죠"('유형'의 영어 동의어) → "저는 앞장서는 사람이죠"로 고침.
- 경계 사례(유지): p05 "점 보는 거랑 비슷한가"(점수 아님), p16 "불안한 사람 아니에요"(불안형 아님), p19 "목표형 인간"(브리프 예시 표현), p07 번아웃은 진단명 대신 증상 장면(가슴 두근거림·휴직)으로만 서술.
- MBTI 네 글자: 사전 지식 7명의 "검사를 대하는 태도" 섹션에만 있음.
- 주의: Read 전수 확인 뒤 MBTI 문장 추가로 bio 8개(p03,p06,p09,p11,p19,p20,p24,p27)를 다시 썼다. 바뀐 부분은 해당 문장 1–2개뿐이고 새 금지어는 넣지 않았지만, 고친 뒤에 Read로 다시 확인하지는 않았다.
